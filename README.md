# W3X 一键解包工具（W3X Unpacker）

一款**傻瓜式**的魔兽争霸3（含重制版）自制地图解包工具。把 `.w3x` 拖进来，一键解出地图里藏着的装备/技能/数值数据。

针对「SLK 优化图」设计——这类地图的装备数据存在 `Units\ItemStrings.txt` 和 `itemdata.slk` 里，普通工具（如 `xdep`）解不开，本工具用 `mpyq` 按正确路径直接读取，全量提取。

## ✨ 功能特性

- **自动识别重制版头**：自动剥离 `HM3W` 重制版封装头，原始 `.w3x` 直接拖入即可，无需手动转换
- **全量提取**：从 `Units\` 正确路径读出 `ItemStrings.txt` / `itemdata.slk` / `abilitydata.slk` / `unitbalance.slk`
- **完整解析**：物品名称 / 稀有度 / 槽位 / 装备属性（Ubertip）一条不漏，并去除魔兽颜色码
- **三种输出**：`解包报告.html`（阅读版）· `物品清单.md` · `物品数据.json`，另附原始 SLK 与数值表 JSON
- **图形界面**：拖拽即用、多地图队列、实时日志、一键打开输出
- **绿色免安装**：单文件 exe，无需安装 Python

## 🚀 快速使用

### 图形界面（推荐，无需 Python）
双击 `W3X一键解包.exe`，把 `.w3x` 拖进窗口（或拖到 exe 图标上），点「一键解包」即可。

### 命令行（需本机装有 Python 3）
把 `.w3x` 拖到 `一键解包.bat` 图标上松开；或手动执行：

```bash
python unpack.py "你的地图.w3x"
```

## 📂 输出结构

地图同目录下生成 `<地图名>_解包输出` 文件夹：

| 文件 | 说明 |
|---|---|
| 解包报告.html | 阅读版报告（浏览器打开） |
| 物品清单.md | Markdown 汇总表 |
| 物品数据.json | 完整结构化数据（名称/稀有度/槽位/属性） |
| raw/ | 解出的原始 SLK / 文本文件 |
| *.slk.json | 数值表（itemdata 等）转成的 JSON |

## ⚙️ 支持说明

- 核心依赖 `mpyq`（本地已内嵌，无需额外安装）。
- 仅支持「SLK 优化图」；普通地图数据存于 `war3map.j` 脚本，暂不支持。
- 工具只读地图、只写输出、不联网、不覆盖原图。

## 📜 许可

仅供学习研究使用。地图版权归原作者所有，本工具仅作数据提取，不参与任何地图内容的再分发。
